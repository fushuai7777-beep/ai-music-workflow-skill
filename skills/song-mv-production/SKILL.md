# 歌曲 MV 制作

按用户当前授权的阶段推进。用户说继续时，先从最新审片记录、可编辑表和已生成文件确认下一段。保留上一次可用版本；用户确认的判断才写成已验收。默认本地处理。使用外部图像、视频、音频或协作服务之前，先说明服务和拟发送的具体文件、片段或衍生提示词，等用户明确确认。此 Skill 本身不授权上传、公开发布或搭建应用。

小墨分镜、资产提取、导演助理、H3 提示词和 HandRaw 是可选的辅助 Skill。环境已有对应 Skill 时可以调用。其余环境按下列步骤完成分镜、资产、动作拆解和提示词。

## 制作顺序

1. **锁定输入。** 记录歌曲名、定稿音频版本、时长、正式歌词、实际送唱稿及创作意图。两种歌词不同时，用送唱稿对齐，用正式词显示。缺材料先找现有项目记录；不可由文件名猜定稿版本。音频原件只读。
2. **整首对齐和核听。** 用本地强制对齐找出每句首尾，保留逐字结果，覆盖每次重复、念白和拖腔。自动转写和波形用来查疑点。对齐冲突时保存候选，不把毫秒精度冒充听准。交付整首位置表及能播放定稿音频的滚动歌词页，至少支持点击定位、慢放和单句循环。用户核听确认后进入分镜；以后发现单个动作卡点仍可局部回听，不静默覆盖旧表。
3. **先交文字分镜定稿，再出图。** 歌词核听后用小墨分镜（`storyboard-director`）辅助写清构图、机位、角色站位、视线、情绪、动作落点与接镜。同场景用窗框、门、栏杆等固定物说明空间关系。给一份可手改的表，每镜包含镜号、段落、原曲时间码和歌词、分镜描述、图片栏。原曲时间、样片时间和画面切点分列。文字分镜未定稿时，先解决结构和动作，不成批生成图。
4. **定画风，筛底模与 LoRA，再出空景、角色和道具。** HandRaw 可用于选画风和准备生图提示。画风确认后，按[多参考镜头制作](references/multi-reference.md)检查本地底模与 LoRA，必要时查发布者资料补充候选。
   - 用小墨资产提取（`character-analyzer`）列出背景、角色、道具及复用版本。遇到行走、抓握、起跳、遮挡切换等复杂动作，先用导演助理（`director-assistant`）拆清起势、接触、发力、收势和相邻镜承接，再决定要补画哪些中间姿势。普通镜头按分镜表直接准备素材。各 Skill 提供构图、资产和动作方法，以本项目已确认的画风和原曲时间轴为准。
   - 同场景复用同一版干净背景，锁定构图、尺度、光色和前后景关系。活动角色和道具单独出透明素材，检查比例、服装、道具形状和遮挡。把分镜图和素材引用回填到可编辑表，请用户确认素材版本。
5. **定稿素材后逐镜确认提示词，以多图参考为默认视频流程。** MiniMax H3 镜头用 `h3-prompt-writing` 把已确认的分镜和参考素材转换为 H3 提示词，并按实际接线标明每个输入的编号、版本和用途。先写共用画面规则，再按时间写起始站位、动作、接触点、歌词落点和结束状态。接续动作可引用上一镜实际采用的尾帧，参考动作节奏或线条可接入已获授权的短视频。提示词确认后，先用同一代表性短镜验证有价值的底模或 LoRA 候选，再按效果选定配置并逐镜生成。端点必须吻合时用首尾帧或本地分层合成。按[多参考镜头制作](references/multi-reference.md)接线并保存实际运行记录。
6. **用 30～60 秒有声样片验证。** 优先选覆盖叙事或情绪转折的段落，以定稿音频为时钟。按实际导出帧数核对剪辑采用区间，本地生成按[试片帧数与显存记录](references/multi-reference.md#试片帧数与显存记录)保存分阶段数据。静音检查动作是否读得懂，带声检查情绪转折和关键落点。用有明确验收点的几秒短片验证高风险动作。样片经审阅后再按主歌、副歌等段落制作，反馈以镜号和版本落地。
7. **合片与审片。** 保留每段版本，整片用一条连续定稿原声。检查接缝、字幕和音画同步。抽查每镜的首帧、动作峰值和末帧，尤其是脸、眼睛、手脚和活动道具的变形、缺失、重影及模糊。同场景对照上一镜采用的末帧和当前镜采用的首帧，核对主体位置与尺度、动作方向、接触点、遮挡和背景光色。复杂动作失真或接不上时，可用导演助理回查分解和素材缺口，再按镜重生成、补动作或分层修复并复查相邻接缝。局部修订同时交有声短片和更新后的完整片。
8. **按需制作清晰度样片和不同画幅。** 清晰度问题先查源画布、素材和成片的实际尺寸。可重渲染时，用同一小段对照直接放大和原生重渲染，按剪边、字形和纹理的实际表现决定是否重跑全片。竖屏先评估两侧动作和字幕，再决定用完整横版入框、逐镜重构图或两者混用。见[成片检查和交付](references/review-template.md#成片检查和交付)。
9. **确认定稿并交付。** 归档成片、可编辑分镜、时间轴、核听页、样片和验收记录，记录剩余候选和复跑所需环境。制作人明确确认后，记录定稿版本和对应画幅。用户指定原歌曲文件夹并要求交付时，复制已确认的文件，核对目标和归档原件的 SHA-256，遇到内容不同的同名文件先保留现有文件。

用 [交付和审片模板](references/review-template.md) 处理需要交表、发样片或打包的任务。创作决定、参考风格、是否扩大制作范围和最终放行交由制作人确认；已确认的步骤不重复问。

已安装 `lyric-subtitle-design` 时，可用它处理歌词字体、排版、入场动作和剪映交接，复用本项目已核听的时间轴和画幅。
