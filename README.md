# AI Music Workflow Skill

面向歌曲创作的本地优先 Skill：在助手对话中整理需求、确认歌词、准备 Suno 制作包，记录生成批次、人工选曲和定稿归档。

当前版本：`0.1.0-skill-preview.20261010.1`，**公开试用预览版，非正式稳定版**。这是独立 Skill 仓库，不包含旧应用后端、网页控制台或旧 Git 历史。

## 下载与开始

1. 打开 [预发布页面](https://github.com/fushuai7777-beep/ai-music-workflow-skill/releases/tag/v0.1.0-skill-preview.20261010.1)，下载 Assets 中的 `ai-music-workflow-0.1.0-skill-preview.20261010.1.zip` 和 `CHECKSUMS.sha256`。
2. 核对 ZIP 的 SHA-256，然后按 [独立安装与使用说明](skills/ai-music-workflow/README.md) 安装。这个 ZIP 含完整的五文件 Skill；GitHub 自动生成的 Source code 包是开发仓库快照，不是同一个安装包。
3. 在支持本地 Skill、文件读写和命令执行的宿主中调用 `$ai-music-workflow`，核对实际加载路径与版本。
4. 第一次任务先确认总项目目录，再确定单首歌曲目录。没有默认盘符，不把歌曲材料保存在 Skill 安装目录中。

示例请求：

> 使用 $ai-music-workflow 帮我创作一首女声小清新歌曲。先问我总项目文件夹位置，只做歌词和制作包，未经我确认不要生成。

本地脚本的已验证环境为 Windows、Python 3.12；只用标准库，无需启动旧应用或配置模型 API Key。自动操作 Suno 另外依赖宿主当次可用且已授权的浏览器能力，登录与验证码由用户完成。无浏览器或下载能力时可以手动接管。

## 工作流与边界

- 先确认需求和歌词，再确认制作包；用户明确授权一次生成后才提交。结果不明时先核对，不重复点击。
- 用户听审并选定准确歌曲 ID；下载前将选定歌曲整理到歌曲同名工作区，核对后获取所需格式。
- 默认交付选定版本的 MP3 与 WAV；两种文件分别核对，缺少要求格式时不能归档成通过。
- 新对话通过原歌曲目录和 `project.json` 恢复，不依赖聊天历史，也不另建空项目冒充恢复。
- 启动检查、网页连接、文件下载、完整解码、人工听审及公开发布是不同的验收层级。

脚本不会登录、生成或下载音乐，也不保证平台权益、连接稳定性或歌曲艺术质量。公开发布、费用、账号/权限修改、安装升级、迁移与删除都需明确授权。详细规则见 [SKILL.md](skills/ai-music-workflow/SKILL.md) 和 [Suno 操作与恢复](skills/ai-music-workflow/references/suno-workflow.md)。
