## 已发现的不一致与处理

| 差异 | 处理方式 |
| --- | --- |
| 2025 上传页写免费 60 秒/付费 8 分钟，当前定价页写免费 8 分钟/付费 30 分钟 | 旧文章可参考入口，不沿用旧额度；具体上传限制再看账号、操作和文件类型。 |
| 产品首页部分 FAQ 仍讲 v5.5，而模型页已介绍 v6 系列 | 以当前模型选择器和所用工具支持为准，不默认强制某版本。 |
| Voices 旧 FAQ 写某模型版本限制 | 不把旧模型限制推广到新版；查当前 Voice 与生成工具兼容性。 |
| Cover 早期文档含免费试用和仅自有作品表述，当前 Remix/工具说明范围不同 | 不承诺免费；按源权限、当前报价和权利要求判断。可生成不代表可商用。 |
| 分轨说明有 10 点/单轨和 20 点/两轨成对输出 | 执行前按实际输出条数和报价确认总额，不用单轨价格承诺整次成本。 |
| Studio 2.0 概览提 MP3/32-bit WAV，较新 Export 页说 WAV | 现场查看导出选项；不得把转码文件冒充平台原始格式。 |
| 旧商用口径只强调生成时会员；现行条款及帮助页加入获准下载，Remix 帮助又区分自有与他人作品 | 不按旧记忆给版权/商业承诺。逐首保存授权、来源和获准下载证据，冲突须向官方确认；本文不是法律审查。 |
| 网页支持某功能，但当前 MCP 32 项里没有它 | 标为网页补缺，不伪造 API，也不说整个平台不支持。 |

- 价格、点数、月额度、模型、文件限制、版权、账户权限与工具参数，在相关动作前重新核查；这份文档不是永久价格表。
- 只更新受影响条目、日期和来源，不把本次歌曲细节、账号、API Key、回调地址、签名链接或私人素材带入分发 Skill。
- 官方说明、当前工具定义、真实调用、落盘/试听四类证据分开。新增能力若只发现定义，写“已加载，未实测”；不要把本文整理当作 32 项功能全部跑通。
